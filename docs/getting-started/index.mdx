:::info
After running Seerr for the first time, configure it by visiting the web UI at
the configured address and completing the setup steps. The first-run page lets
you choose built-in self-signed HTTPS, a provided certificate, or the default
warning-bearing trusted-LAN HTTP session mode. Save the choice and restart
before the first media-server login. Existing upgrades migrate disabled-TLS
installations to the working direct-HTTP default;
see [built-in HTTPS for a direct LAN deployment](/using-seerr/advanced/built-in-tls)
for the full flow.
:::
