Local users can now select Edit on their profile picture to upload a JPEG, PNG, or WebP image. Plex, Jellyfin, and Emby profile pictures continue to follow their linked media-server accounts. Absolute Plex avatar URLs are now accepted by the secure remote-image cache, preventing valid linked profile pictures from falling back to the generic avatar.
